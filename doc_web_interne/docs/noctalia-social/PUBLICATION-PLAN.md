## Objectif

Développer la complétion, les partages, les visites de profil et les abonnements
avec des vidéos oniriques courtes. Le lot initial de 16 vidéos reste le registre
principal ; la cadence opérationnelle passe à trois vidéos par jour à partir du
06/08/2026, avec les créneaux supplémentaires documentés dans le plan du
community manager. Le calendrier V2 Magnific reste un registre éditorial séparé.

## Règles de production

- Format vertical `9:16`, `720p` minimum.
- Finale native de `10,0 s` ou d'environ `12 s`. Les deux durées ont été
  explicitement validées le 2026-07-31.
- Anomalie impossible active dès la première image.
- Escalade visuelle toutes les `1,5–2 s`.
- Dernière image clairement différente de la première.
- Aucun retour, boucle, reset ou end card.
- Ambiance ou musique instrumentale native uniquement.
- Les droits audio sont confirmés pour tous les assets actuels, décision
  enregistrée le 2026-07-31.
- Aucun texte IA ni @mention dans le corps des posts, sauf obligation explicite
  de la plateforme ; les labels natifs séparés du texte peuvent rester actifs
  lorsqu'ils sont requis.
- Aucun dialogue, voix, chant, texte, sous-titre, logo, CTA ou interface.
- Aucun visage identifiable, violence ou référence reconnaissable à une franchise.
- Prompts de génération rédigés en anglais.
