# Noctalia — Plan de publication TikTok et Instagram Reels

Dernière vérification Magnific : 2026-07-28.

## Objectif

Développer la complétion, les partages, les visites de profil et les abonnements
avec des vidéos oniriques courtes. Le mois 1 publie quatre vidéos par semaine :
lundi, mercredi, vendredi et dimanche.

## Règles de production

- Format vertical `9:16`, `720p` minimum.
- Finale native exacte de `10,0 s`.
- Anomalie impossible active dès la première image.
- Escalade visuelle toutes les `1,5–2 s`.
- Dernière image clairement différente de la première.
- Aucun retour, boucle, reset ou end card.
- Ambiance ou musique instrumentale native uniquement.
- Aucun dialogue, voix, chant, texte, sous-titre, logo, CTA ou interface.
- Aucun visage identifiable, violence ou référence reconnaissable à une franchise.
- Prompts de génération rédigés en anglais.

## Test d'identité « Plongée Noctalia »

Le test consiste à montrer une personne endormie dans une chambre déjà impossible,
puis à plonger dans son rêve avant `1,0 s`. Cette ouverture est une signature
narrative, pas un carton de marque.

| Concept | Image de départ | Vidéo | Créneau |
|---|---|---|---|
| Océan céleste | Disponible dans les assets mutualisés | Non générée | Non planifié |
| Cité inversée | Disponible dans les assets mutualisés | Non générée | Non planifié |
| Forêt cosmique | Deux variantes dans les assets mutualisés | Non générée | Non planifié |

Ces trois tests ne remplacent aucun créneau V2 avant validation. Une modification du
calendrier doit être inscrite ici, sans créer une nouvelle image de calendrier.
