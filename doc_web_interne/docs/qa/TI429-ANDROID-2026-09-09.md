### Méthode du cas long

Le seuil de 10 000 est un cas de robustesse du plan QA, **pas une limite de gestion du récit**. La règle TI-414 est la conservation de l’original intégral, distincte des limites de traitement IA.

L’injection `adb input text` de 10 000 caractères n’a fourni que 703 caractères dans le champ : échec de cette méthode d’injection, avant sauvegarde. Le scénario n’a pas été marqué réussi à partir de cette tentative.

La reprise prépare uniquement le texte synthétique dans le presse-papiers natif via le débogueur du client local, puis utilise sélection complète et collage Android dans le champ. L’ancien contenu texte du presse-papiers est conservé temporairement en mémoire de l’app, restauré après collage, sans affichage ni export dans les logs. Aucune injection directe dans le stockage, les props ou l’état React. L’arbre UI expose ensuite le texte exact attendu, comparé intégralement avant sauvegarde, dans la fiche et après relance. Le texte tronqué de la première tentative était exclusivement synthétique et a été remplacé dans ce même brouillon de test.
